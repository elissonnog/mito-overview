# Provisional public reduced short-read workflow evidence

The repository tracks a GM11906 compatibility example made by pooling three public single-cell ATAC-seq libraries into a pseudo-bulk for the reduced short-read report profile. The current lightweight assets were regenerated by the 17-case local v0.3.0 matrix from the six verified accession FASTQs. They are pre-release supporting evidence, not evidence bound to the eventual final release commit.

## Evidence scope
- provisional evidence snapshot: `2026-07-21`
- local matrix result: all `17/17` required cases and `256/256` scientific oracle assertions passed under macOS process-tree network isolation
- tracked-output status: regenerated from the seven-FASTQ matrix; not final v0.3.0 release-packet evidence
- source runs: `SRR10804585`, `SRR10804590`, and `SRR10804657`
- sample context: three single-cell ATAC-seq libraries from one GM11906 lymphoblastoid line, pooled as a pseudo-bulk
- profile: `READ_MODE=short`, `ASSAY_TYPE=targeted_mt`
- runner: `scripts/run_public_shortread_validation_gm11906.sh`

The three public runs (`GSM4238454`, `GSM4238459`, and `GSM4238526`) were combined for the reduced-profile report. GEO identifies all three as single-cell ATAC-seq libraries from GM11906. The local matrix rebuilt the pooled paired FASTQs and BWA-MEM alignment from the six sealed FASTQs before running the report profiles.

## Final v0.3.0 release binding

Before these observations can support final v0.3.0 release acceptance, the matrix must be rerun from the exact clean `FINAL_SHA` on macOS and Ubuntu. The required audit packet must bind that commit to input hashes, derivation commands, logs, normalized outputs, filter-profile checks, package artifacts, and exact-commit GitHub Actions evidence. The packet must then pass its generated `verify_bundle.sh` from both its build directory and a fresh ZIP extraction.

Until that exact-commit packet exists and passes, the values below remain local provisional observations. All final release, CI, tag, and GitHub-asset gates remain **pending**.

## Default profile
The example-specific candidate thresholds are `MIN_CALLABLE_DEPTH=10` and `MIN_ALT_ALLELE_FRACTION=0.20`. The default observation filters are `ALLELE_MIN_BASE_QUALITY=13`, `ALLELE_MIN_MAPPING_QUALITY=20`, and `ALLELE_MIN_READ_MEAN_QUALITY=10`.

The provisional default run reported:

- `33` candidate sites
- `44,052,664` accepted observations
- `7,293,106` excluded observations
- `m.8344A>G` at depth `1,027`, with `740` alternate observations and pooled observed alternate allele fraction `0.720545`
- `MT-TK` feature context and `tRNA_variant` consequence output for position `8344`

## Mode-gated statuses
In the provisional run, the reduced short-read targeted-mt profile wrote `not_applicable` status outputs for `deletions`, `copy_number`, `cosegregation`, `numt_qc`, `phymer_haplogroup`, `identity_qc`, `circularity_qc`, and `methylation_exploratory`. Optional `mvtool_annotation` was `not_configured` when disabled.

## Repeatability and claim scope
The matrix first reconstructed the pooled FASTQs and alignment, then used that newly generated derivative for two default report invocations. Their normalized TSVs and decoded PNG pixels matched exactly, and their HTML structures matched. This separates report repeatability from alignment variability while still testing the raw-FASTQ derivation once in the matrix. The evidence supports workflow execution, report/resource generation, descriptive filter dependence, and mode gating only. The pooled alternate allele fraction is not a per-cell value, a calibrated sample heteroplasmy estimate, or evidence of short-read WGS performance.
